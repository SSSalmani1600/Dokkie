Dit is een webpagina met een zwarte achtergrond

Hier is wat tekst op een zwarte achtergrond.

In deze code wordt de achtergrondkleur van de -tag ingesteld op zwart met behulp van CSS (background-color: black;). Je kunt ook de tekstkleur aanpassen aan je voorkeur door de color-eigenschap in te stellen op de gewenste kleur. Kopieer en plak deze code in een HTML-bestand en open het in je webbrowser om een webpagina met een zwarte achtergrond te zien. Pas de inhoud en stijl aan zoals je wilt!
